# 中国 A 股行情（cn-equity）

> 创建日：2026-10-26。产品面唯一名称；**新浪等只是采集源**（`data_source`）。  
> **模块边界 SSOT**：[行情模块边界](./2026-10-26-行情模块边界.md)。表结构：[market schema](./2026-10-26-market-postgres-schema.md)。

## 本模块是什么 / 不是什么

| 是 | 不是 |
|---|---|
| 中国 A 股**产品读面**（API + UI） | 采集供应商（sina/adata） |
| research 包 `app.cn_equity` + 路由 `/cn-equity` | qdb 引擎本身 |
| 历史-only 产品面（主读 Postgres `market`） | market-data 服务（那是币安/RWA）；默认无盘中 qdb |

## 命名

| 层 | 名称 |
|---|---|
| 研究 API | `/cn-equity/*` |
| BFF | `/api/cn-equity/*` |
| 前端 | `/markets/cn` |
| 代码包 | `apps/research/app/cn_equity` |

可选上游库 **adata**（agent 对接前可读）：<https://github.com/1nchaos/adata>。边界与禁令见 [行情模块边界 §3.1](./2026-10-26-行情模块边界.md)。

旧名 `ashare` / `/markets/ashare` / `app.ashare` **已删除**，不再提供兼容路由。

## 读路径（硬规则）

| 数据 | 主读 | 回落 | 禁止 |
|---|---|---|---|
| 代码表 | qdb `cn-equity:codes`（history-ingest 刷新） | PG security | 上游 |
| 列表报价 | `market.bar_daily` 末日 | 空 + note | 上游；默认无盘中 qdb |
| 五档 / 盘中 | 关闭（空 + note） | — | 上游 |
| K 线 `history`（**默认**） | `market.bar_*`（日 + 5m/15m/1h） | qdb 短窗（标明 `source`） | 上游 |
| K 线 `realtime` / `merged` | 可选；无热数据时 realtime 空 | — | 写 `market` |

缺数据 → 空/诚实 note，等 **history-ingest** 补齐；**禁止**读路径回源。  
`COLLECTOR_SKIP_CN_EQUITY=1`（Compose 默认）：collector 不写 A 股盘中。全市场日线 + 分钟多周期短窗由 **history-ingest** 回补。

## 主要接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/cn-equity/codes?category=` | 代码表；`stock`（qdb）/ `index`·`etf`·`convertible`（`market.security`） |
| GET | `/cn-equity/quotes` | 列表价；优先末日 `bar_daily`（历史模式） |
| GET | `/cn-equity/index-strip` | 顶栏主流指数（冷日线） |
| GET | `/cn-equity/klines/{code}` | K 线；默认 `view=history`；`k_type`=1d/1w/1M/5m/15m/30m/60m |
| GET | `/cn-equity/five/{code}` | 五档；历史模式下通常空 + note |
| GET | `/cn-equity/intraday/{code}` | 分时用历史 5m；缺则注记 |
| GET | `/cn-equity/fundamentals/{code}` | 个股冷域：资金流 / 财务 / 股本 / 行业 / 解禁（只读 `market`） |
| GET | `/cn-equity/plates` · `/plates/.../members` · `/plate-flow` | 板块目录 / 成分 / 板块资金流 |
| GET | `/cn-equity/sentiment/summary` | 两融 / 北向 / 热榜摘要 |
| GET | `/cn-equity/lhb?date=` | 龙虎榜日终 |
| GET | `/cn-equity/lhb/{list_id}/detail` | 龙虎榜席位明细 |
| GET | `/cn-equity/lhb-days` | 有数据的上榜日 |
