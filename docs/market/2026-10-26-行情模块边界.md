# 行情模块边界（硬性）

> 创建日：2026-10-26。本文是行情数据面的 **模块职责与禁令 SSOT**。  
> 表结构见 [market-postgres-schema](./2026-10-26-market-postgres-schema.md)；A 股产品面见 [cn-equity](./2026-10-26-cn-equity.md)；qdb 协议见同级仓手册 + [qdb-行情库](./2026-10-20-qdb-行情库.md)。

## 1. 一句话分层

| 模块 | 一句话 | 可写 | 可读 |
|---|---|---|---|
| **上游（Upstream）** | 公开行情供应商（新浪、币安、RWA bapi…） | — | **仅授权采集族** |
| **data_source** | 供应商在库内的登记码（`sina` / `binance`…） | 采集族 | 运维/对账；**不是** API 资源名 |
| **collector** | 盘中回源（报价/成交/docs + 种子 K） | → qdb **与** → `market` | 上游 |
| **history-ingest** | 冷历史持续回补边车（近半年日线） | → `market.bar_daily`（默认不写 qdb trades） | 上游 + 读 qdb codes doc |
| **qdb（热）** | 盘中快照、未闭合棒、订阅、短窗引擎 K | collector | research / market-data / 经代理的前端订阅读 |
| **Postgres `market`（冷）** | 已闭合历史棒、复权因子、交易日历、停牌、冷维表 | collector / history-ingest / adata-ingest / akshare-ingest / 授权迁移 | research（历史）；回测/翻历史主读 |
| **adata-ingest** | adata/东财 → 冷维表与日终舆情（P0–P3） | → `market.*`（不写 qdb） | 上游 |
| **akshare-ingest** | akshare → 冷维表与日终舆情（P0–P3，并行） | → `market.*`（不写 qdb） | 上游 |
| **cn-equity** | 中国 A 股**产品**读面（API/UI 名） | 不写存储 | 读 qdb + `market`；对外路径 `/cn-equity` |
| **market-data** | 币安/RWA 等非 A 股读适配 + `/qdb/ws` 代理 | 不写行情库 | **只读 qdb**（本阶段不读 `market`） |
| **gateway / BFF / frontend** | 传输与展示 | 不写行情库 | 只打本仓 API；零上游 |

```text
上游 ──► collector ──────────┬──► qdb（热）
                             └──► market.*（冷，种子/盘中附带）
上游 ──► history-ingest ─────────► market.bar_daily（近半年缺口扫描）
上游 ──► adata-ingest ───────────► market.*（日历/维表/资金财务/舆情日终）
上游 ──► akshare-ingest ─────────► market.*（同上，source_code=akshare，并行）
                                      ▲
research /cn-equity ── history ───────┘
                 └── realtime / quotes / depth / ws ──► qdb
market-data ─────────────────────────────────────────► qdb
frontend / BFF / gateway ──► research | market-data（禁止直连上游）
```

## 2. 禁止混淆的三组名字

| 易混 | 正确归属 | 禁止 |
|---|---|---|
| `sina` / `adata` / `binance` | **仅** `market.data_source.code` 或 collector 实现细节 | 作 OpenAPI tag、路由段、产品模块名 |
| `ashare`（历史名） | **已移除**；勿再出现在路由、BFF、包名、docs key | 任何新代码或文档标题 |
| `cn-equity` / `/markets/cn` | **产品/市场段**名（中国 A 股）；qdb docs `cn-equity:codes` / `cn-equity:depth:*` | 当作采集供应商名 |
| `qdb` | 热存储与引擎 | 当作「全量历史库」或业务资源名 |
| `market` schema | 冷历史域模型 | 与 qdb docs/quotes 混写同一条写入路径而不标明 |

## 3. 各模块允许 / 禁止

### 3.1 上游

- **允许**：被 **授权采集族**（`collector`、`history-ingest`、`adata-ingest`、`akshare-ingest`）拉取。
- **禁止**：出现在 research、market-data、frontend、orchestrator、gateway 业务转发的任何 HTTP/WS 客户端中。

#### 采集源参考（agent 可读）

| `data_source` | 说明 | 上游/库参考 |
|---|---|---|
| `sina` | 当前 A 股盘中/日线主回源实现（collector / history-ingest） | 新浪财经公开接口（实现细节见采集代码） |
| `adata` | A 股量化库；`services/adata-ingest` 经 SDK 写冷表；不作产品路由名 | <https://github.com/1nchaos/adata> |
| `akshare` | AKShare；`services/akshare-ingest` 并行写冷表；不作产品路由名 | <https://github.com/akfamily/akshare> |
| `binance` | 币安现货等 | 币安公开 REST/WS |

写入本仓时仍须经采集族，且只登记为 `market.data_source`，禁止把 `adata` / `akshare` 写进 OpenAPI tag / 路由 / 包名。

**源头 ≠ 库表设计**：`market.*` / qdb 的表结构与产品契约由本系统定义（SSOT）。新增供应商（如 akshare）= 多一条回源实现，经既有写 API（`equitylab_market.pg` / `packages/qdb-*`）填**同一套表**；允许的库变更仅限 `data_source` 登记行。禁止为某一 SDK 加专用表/列、改主键或把供应商形状泄漏进读面。热写 qdb、冷写 `market` 按域分工，不按供应商分叉 schema。

### 3.2 collector

- **允许**：访问上游；经 `packages/qdb-*` 写 quotes/trades/docs；经 `equitylab_market.pg` 写 `market.*`；维护水位。
- **禁止**：被读路径服务「代写」；读路径不得 import 回源逻辑。
- **落点**：`services/collector/`；冷库写经 `packages/market-py`（`equitylab_market`）。

### 3.2b history-ingest（冷历史回补）

- **允许**：访问新浪 K 线；读 qdb `cn-equity:codes` 宇宙；写 `market.bar_daily` + `ingest_watermark`（`dataset=bar_daily_coverage`）。
- **默认不做**：写 qdb trades（避免引擎压力）；全市场分钟半年回补。
- **节奏**：限速扫描缺口（`HISTORY_INGEST_SLEEP_MS` 等）；与盘中 collector **分进程**。
- **落点**：`services/history-ingest/`；与 collector **共享** `equitylab_market`（禁止 Dockerfile 拷贝散文件）。

### 3.2c adata-ingest（adata → market，P0–P3）

- **允许**：经 [adata](https://github.com/1nchaos/adata) SDK 拉日历/证券元数据；指数·ETF **日线**走东方财富 push2his（与 adata east 同源 HTTP；aarch64 上 py_mini_racer 不可用时的兜底）。写 `trading_calendar`、`security`（index/etf/convertible/concept）、对应 `bar_daily`、`ingest_watermark`（`source_code=adata`）。
- **P1**：`plate`/`plate_member`/`index_member`/`share_capital`/`industry_*`/`dividend`→股数口径 `adjust_factor`；东财概念目录/成分走 push2（绕过 adata 缺 CSV / MiniRacer）。`ADATA_INGEST_SKIP_P1=1` 可关。
- **P2**：`capital_flow_daily` / `capital_flow_plate_daily`（概念资金流快照）/ `finance_core`；`ADATA_INGEST_SKIP_P2=1` 可关。分时资金流不进 market。
- **P3**：`lifting` / `margin_balance` / `north_flow_daily` / `lhb_*` / `hot_rank_daily`；解禁走东财（绕过 THS MiniRacer）；`ADATA_INGEST_SKIP_P3=1` 可关。分时北向/热度不进 market。
- **默认不做**：写 qdb；盘中报价；现金除权因子（需 OHLC）；**读路径与 UI**（舆情/资金/财务展示在 cn-equity，本服务只写冷库）。
- **节奏**：整轮后 `ADATA_INGEST_IDLE_SEC`（默认 1h）；限速 `ADATA_INGEST_SLEEP_MS`；股票面用 `ADATA_INGEST_STOCK_LIMIT` / `ADATA_INGEST_P2_STOCK_LIMIT` 控量。
- **落点**：`services/adata-ingest/`；冷库写经 `equitylab_market.pg`。指标 `:9103/metrics`。

### 3.2d akshare-ingest（akshare → market，P0–P3，并行）

- **定位**：与 adata-ingest 同级的**又一个冷写入源头**；不拥有、不扩展 `market` schema。
- **允许**：经 [akshare](https://github.com/akfamily/akshare) 拉日历/证券/日线/板块/资金/财务/舆情日终；经 `equitylab_market.pg` 写**既有** `market.*` + `ingest_watermark`（`source_code=akshare`）。迁移只 `INSERT data_source`。
- **P0–P3**：与 adata 相同的表目标清单（实现分期，不是新表分期）；日线强制未复权（`adjust=""`）；`AKSHARE_INGEST_SKIP_P1/P2/P3` 可关。
- **默认不做**：改库表设计；写 qdb（热域仍归 collector）；盘中报价；产品路由/UI；读路径。
- **并存**：同表 upsert + 分源水位；限速独立（默认 `IDLE_SEC=3600`）。
- **落点**：`services/akshare-ingest/`；指标 `:9104/metrics`。细则 [akshare-ingest](./2026-10-27-akshare-ingest.md)。

### 3.3 qdb（热）

- **存**：snapshots、未闭合 / 短窗 K、docs（如代码表、五档）、订阅流。
- **不存（权威）**：长期已闭合历史的主副本、复权因子序列、交易日历权威表、停牌区间权威表——这些以 `market` 为准。
- **访问**：一律 `packages/qdb-{py,ts,rs}`；业务禁止裸打 `QDB_URL/v1/*`。
- **浏览器**：订阅读经 market-data `/qdb/ws`，订阅逻辑用 TS 客户端。

### 3.4 Postgres `market`（冷）

- **存（基线）**：`security` / `bar_daily` / `bar_minute` / `adjust_factor` / `trading_calendar` / `suspend` / `data_source` / `ingest_watermark`。
- **存（adata 完整冷域，表已建、写入分阶段）**：`share_capital` / `industry_sw` / `security_industry` / `plate` / `plate_member` / `index_member` / `dividend` / `capital_flow_*` / `finance_core` / `lifting` / `margin_balance` / `north_flow_daily` / `lhb_*` / `hot_rank_daily` 等——见 [adata 完整域](./2026-10-27-market-schema-adata完整域.md)。
- **不存**：盘中未闭合棒、WebSocket 推送状态、研报向量、会话审计（后两者在别的 schema/库）；三大报表明细/公告原文等。
- **价格**：交易所原始价；**不存**三份复权 OHLC 行。
- **写者**：collector / history-ingest（及后续 adata 采集 job）；手工迁移须标明 `data_source=manual`。
- **写客户端**：`packages/market-py` → `equitylab_market.pg`。
- **落点**：`infra/postgres/migrations/*market*`；基线 [market-postgres-schema](./2026-10-26-market-postgres-schema.md)；扩展 [adata 完整域](./2026-10-27-market-schema-adata完整域.md)。

### 3.5 cn-equity（产品读面）

- **是**：中国 A 股对外契约与研究层模块（`apps/research/app/cn_equity`、路由 `/cn-equity`、前端 `/markets/cn`）。
- **读规则**：
  - `view=history` / 翻历史：**优先** `market.bar_*`；不足可回落 qdb（须在响应 `source` 标明）。
  - `view=realtime` / quotes / five / 订阅相关：**只** qdb。
  - `view=merged`：history（PG 优先）+ realtime（qdb）在研究层拼接。
- **禁止**：回源上游；把 `adata`/`ashare` 写进 OpenAPI tag / 路由 / BFF；在 BFF 拼上游 URL。

### 3.6 market-data

- **职责**：币安现货、RWA/Ondo 等；qdb 读适配；`/qdb/ws` 代理。
- **禁止**：代理币安/RWA 上游 REST/WS；本阶段读 `market` schema（A 股历史不经此服务）。
- **与 cn-equity**：市场段不同；勿把 BINANCE/ONDO 混进 A 股列表。

### 3.7 gateway / BFF / frontend

- **允许**：反代 `/api/research/cn-equity/*`、`/api/market/*`；展示派生指标（MA 等）仅基于已取回序列。
- **禁止**：直连上游；浏览器直打 `QDB_URL`；把采集源名当导航产品名。

## 4. 读写顺序（门禁）

与 DoD 数据面一致：

1. collector 写入就绪（qdb 有报价/docs；历史则 `market.bar_*` 有行或水位推进）  
2. research / market-data 读通  
3. frontend 展示  

逆序不得报绿。展示集 ⊆ 采集就绪集（或明确「仅目录、暂无报价」）。

## 5. 响应里的 `source` 语义

| 值 | 含义 |
|---|---|
| `qdb` | 本响应主体来自 qdb |
| `postgres` / `postgres:market` | 本响应主体来自 `market` schema |
| `qdb:cn-equity:codes` 等 | qdb docs key（代码表）；**不是**采集供应商名 |
| `sina` | 仅允许出现在采集侧元数据 / `data_source`，不应作为读 API 的主 `source` 宣称「业务来自新浪」 |
