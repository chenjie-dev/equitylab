# 币安现货热冷分离（对齐 A 股）

> 创建日：2026-10-30。边界 SSOT：[行情模块边界](./2026-10-26-行情模块边界.md)。  
> **本轮仅 BINANCE 现货**；RWA / 代币化美股下一版。

## 决策

| 层 | 职责 |
|---|---|
| Postgres `market.bar_daily` / `bar_minute` | 已闭合历史（`exchange_code=BINANCE`） |
| qdb snapshots / docs 短窗 | 报价、盘口、当日未闭合末棒 |
| market-data `/binance/klines` | PG 历史 +（无 `endTime` 时）qdb 末棒合并 |
| collector | 授权回源；闭合棒写 PG；短窗 docs 兼容 |

缺冷数据 → 空数组（短暂可回落 docs，非权威）；**禁止**读路径回源币安 REST。

## 周期落点

- `1d` → `bar_daily`
- 其余币安 interval（含 `3m/30m/1h/2h/4h/6h/12h/3d/1w/1M`）→ `bar_minute.period`（`60m` 读写映射为 `1h`）
- 迁移：`infra/postgres/migrations/20261030_market_binance_bars.sql`

## 开关

| env | 默认 | 说明 |
|---|---|---|
| `BINANCE_KLINE_BACKFILL` | `1` | 启动向 PG 翻页回补闭合棒 |
| `BINANCE_KLINE_PG_BACKFILL_PAGES` | `10` | 每 symbol×interval 最多页数（每页≤1000） |
| `BINANCE_KLINE_INTERVALS` | 全周期列表 | 与前端现货台对齐 |
| `BINANCE_KLINE_LIMIT` | `180` | docs 短窗硬顶（非 PG 深度） |

## 冒烟

```bash
psql "$DATABASE_URL" -f infra/postgres/migrations/20261030_market_binance_bars.sql
docker compose up -d --build collector market-data
docker compose exec -T postgres psql -U equitylab -c \
  "SELECT count(*) FROM market.bar_minute bm JOIN market.security s USING(inner_code) WHERE s.exchange_code='BINANCE' AND period='15m'"
curl -s 'http://localhost:3000/api/market/binance/klines?symbol=BTCUSDT&interval=15m&limit=500' | jq 'length'
```
