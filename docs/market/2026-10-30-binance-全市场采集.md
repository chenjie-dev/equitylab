# 币安现货全市场采集

> 创建日：2026-10-30。热冷：[binance 热冷分离](./2026-10-30-binance-热冷分离.md)。边界 SSOT：[行情模块边界](./2026-10-26-行情模块边界.md)。

## 目标

- 宇宙：`exchangeInfo` 全部 `status=TRADING` 现货（含 USDT/BTC/ETH/FDUSD 等计价）；不剔杠杆代币。
- 上线：报价 + 盘口 + 成交 **全开**；冷 K 线 **后台慢补**。
- 展示集 ⊆ 采集：前端目录只读 collector 写入的 `binance:symbols`（经 market-data）。

## 采集

| 组件 | 行为 |
|---|---|
| 宇宙刷新 | 启动 + 周期拉 REST `exchangeInfo`；写 qdb doc `binance:symbols` |
| WS | 分层分片：**热** 四流含 depth@100ms；**冷** 仅 bookTicker+ticker（全市场 depth WS 会打满 write_gate） |
| 盘口 | 热门 WS；冷端 REST 轮转写入 `binance:depth:*`（低优先；BTC/ETH 计价对优先） |
| 冷 K | 独立慢队列：symbol×interval 每步 1 页 upsert PG |
| 自愈 | catalog 每 60s 检查；qdb 重建后自动重发 `binance:exchangeInfo` |
| env | `BINANCE_SYMBOLS=all`；`BINANCE_WS_HOT` 可扩热门；`BINANCE_WS_SHARD_STAGGER_SEC` 错峰 |

## 读面

- `GET /binance/exchangeInfo`（或 `/binance/symbols`）← qdb `binance:symbols`，禁止回源。
- 现货台列表/搜索读该 catalog；无 PG 历史时图表可空或提示回补中。

## 非目标

- RWA；读路径回源；合约。
