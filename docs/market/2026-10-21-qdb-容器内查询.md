# qdb 容器内用 `qdb-client` 查询

> 创建日：2026-10-21。用 Compose 里的 `qdb` 容器跑**只读** `qdb-client`，交互 / 单条 SQL 查行情。  
> 客户端语法权威：同级仓 `../qdb/docs/manual/client.md`、`sql.md`。本仓落点：[qdb 行情库](./2026-10-20-qdb-行情库.md)。

## 两个二进制别搞混

| 命令 | 作用 |
|---|---|
| `qdb` | **服务进程**（Compose 已在跑）。再启会报「本机已有一个 qdb 实例」 |
| `qdb-client` | **只读查询**。打开同一数据目录 `/var/lib/qdb`，提示符 `qdb>`，可与服务共存 |

镜像需包含 `qdb-client`（`../qdb` Dockerfile 已打入）。若容器里没有该命令：

```bash
docker compose up -d --build qdb
```

## 前提

```bash
cd /path/to/equitylab
docker compose up -d qdb collector
docker compose ps qdb
docker compose exec qdb which qdb-client   # 应打印 /usr/local/bin/qdb-client
```

数据目录：容器内 `/var/lib/qdb`（卷 `equitylab-qdbdata`）。

## 进入交互查询（推荐）

```bash
# 仓库根；-it 才能进 qdb> 提示符
docker compose exec -it qdb qdb-client /var/lib/qdb
```

或先 `sh` 再进客户端：

```bash
docker compose exec -it qdb sh
qdb-client /var/lib/qdb
```

出现 `qdb>` 后：

```text
qdb> help
qdb> ll
qdb> SHOW TABLES
qdb> .schema
qdb> DESCRIBE klines
```

退出：`Ctrl-D` 或 `quit` / `.quit`（以 `help` 打印为准）。

## 常用 SQL（EquityLab 符号）

```text
-- 表一览
qdb> SHOW TABLES

-- A 股快照
qdb> SELECT symbol, last, bid_px1, ask_px1, seq
     FROM snapshots WHERE symbol = 'SSE:600519'

-- A 股日 K
qdb> SELECT ts, open, high, low, close, volume
     FROM klines WHERE symbol = 'SSE:600519' AND period = '1d' LIMIT 20

-- 币安现货
qdb> SELECT symbol, last FROM snapshots WHERE symbol = 'BINANCE:BTCUSDT'
qdb> SELECT ts, open, high, low, close, volume
     FROM klines WHERE symbol = 'BINANCE:BTCUSDT' AND period = '1h' LIMIT 20

-- Ondo 代币化美股
qdb> SELECT symbol, last FROM snapshots WHERE symbol = 'ONDO:AAPL'
qdb> SELECT ts, open, high, low, close, volume
     FROM klines WHERE symbol = 'ONDO:AAPL' AND period = '1h' LIMIT 20

-- 最近成交（有则查）
qdb> SELECT ts, price, volume, seq FROM ticks
     WHERE symbol = 'SSE:600519' LIMIT 20
```

过滤规则（手册摘要）：

| 表 | 查询时一般要带 |
|---|---|
| `symbols` | 无 |
| `ticks` | 建议 `symbol` |
| `snapshots` | `symbol` |
| `klines` | `symbol` **和** `period`（`1s`/`1m`/`5m`/`15m`/`1h`/`4h`/`1d`） |

价格在 SQL 结果里多为缩放整数（`PRICE_SCALE=10000`）；解读时心算 ÷10000，或对照 HTTP `GET /v1/klines`（已还原小数）。

## 单条命令（不进交互）

```bash
docker compose exec qdb qdb-client /var/lib/qdb -c "SHOW TABLES"

docker compose exec qdb qdb-client /var/lib/qdb -c \
  "SELECT ts, open, high, low, close, volume FROM klines WHERE symbol = 'ONDO:AAPL' AND period = '1h' LIMIT 5"

docker compose exec qdb qdb-client /var/lib/qdb -c \
  "SELECT symbol, last FROM snapshots WHERE symbol = 'BINANCE:BTCUSDT'"
```

## 订阅变更（可选）

交互里（会持续打印，`Ctrl-C` 结束）：

```text
qdb> SELECT last, bid_px1, ask_px1, seq FROM snapshots
     WHERE symbol = 'BINANCE:BTCUSDT' SUBSCRIBE

qdb> .watch snapshots BINANCE:BTCUSDT
qdb> .watch klines SSE:600519 1m
```

## docs（盘口 / RWA board 等）

`qdb-client` SQL **不查** `POST /v1/docs` 里的键值。那些仍用 HTTP：

```bash
# 宿主机或容器内
curl -s 'http://127.0.0.1:9090/v1/docs?key=rwa:board' | head -c 300
curl -s 'http://localhost:9090/v1/docs?key=binance:ticker:BTCUSDT' | head -c 200
```

常用 key 见 [qdb 行情库](./2026-10-20-qdb-行情库.md)。

## 注意

1. **不要**再跑 `qdb /var/lib/qdb`：服务已在跑。查询只用 `qdb-client`。  
2. `qdb-client` 读的是已 `fsync` 的 WAL；刚写入、尚未落盘的尾部可能略滞后。  
3. 无行情时先确认 collector：`docker compose logs -f collector`。  
4. 完整语法：`../qdb/docs/manual/client.md`、`sql.md`。

## 排障

| 现象 | 处理 |
|---|---|
| `qdb-client: not found` | `docker compose up -d --build qdb` 重建镜像 |
| `本机已有一个 qdb 实例` | 你执行的是服务二进制 `qdb`，改用 `qdb-client` |
| `(0 rows)` | 符号/周期错，或 collector 未写入；对照 `SHOW TABLES` / snapshots |
| `exec` 无 TTY | 交互必须加 `-it` |
| docs 查不到 | SQL 不覆盖 docs；改用 `curl …/v1/docs?key=` |
