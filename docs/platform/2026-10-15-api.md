# EquityLab API 参考（MVP）

统一入口优先走 **Gateway**（`http://localhost:3000`）。编排层与研究层也可在 Docker 网络内直连。

## 约定

| 项 | 说明 |
|---|---|
| 内容类型 | 请求/响应默认 `application/json` |
| 健康检查 | 各服务 `GET /health`，返回 `{ status, service, ts }` |
| 错误 | 4xx 客户端问题；502 上游失败；429 网关限流 |
| 鉴权 | MVP 未启用 JWT（见网关 TODO） |
| 追踪 | 请求/响应头 `X-Trace-Id`；缺失则网关或入站服务生成 UUID。详情见 [可观测性](./2026-10-16-observability.md) |

---

## Gateway（`:3000`）

| 方法 | 路径 | 转发目标 | 说明 |
|---|---|---|---|
| GET | `/health` | 本服务 | 网关存活 |
| ANY | `/api/chat`、`/v1/*` | Orchestrator | 对话 / 后续 OpenAI 兼容面 |
| ANY | `/api/research/*` | Research（剥前缀） | 例：`/api/research/rag/search` → `/rag/search` |
| ANY | `/api/market/*` | Market-Data（剥前缀） | 例：`/api/market/quotes/600519.SH` → `/quotes/600519.SH` |
| ANY | 其余 `/api/*` | Frontend | 含 `/api/cn-equity` BFF |
| ANY | `/`、`/markets/*`、`/_next/*` 等 | Frontend | 统一入口页面；`FRONTEND_URL`（Compose 内 `http://frontend:3000`） |

限流：按客户端 IP 滑动窗口，默认每分钟 `RATE_LIMIT_PER_MINUTE=120`。不计入限额：`/api/market/*`（币安/RWA）、`/api/research/cn-equity/*`（中国 A 股只读；列表虚拟滚动会分块拉报价）。对话与其它 research 仍限流。

## Orchestrator（内部 `:8001`）

### `GET /health`

编排层存活探测。

### `GET /tools`

返回已注册工具的 `name` / `description`（不含执行）。

### `POST /api/chat`

**请求体**

```json
{
  "message": "茅台现在多少钱？",
  "sessionId": "可选会话 ID",
  "agent": "auto"
}
```

`agent`：`auto` | `research` | `factor` | `strategy` | `data`。`auto` 时按中英文关键词粗路由。

**响应体（MVP）**

```json
{
  "agent": "data",
  "answer": "……确定性工具摘要……",
  "toolCalls": [{ "name": "get_stock_quote", "args": { "symbol": "600519.SH" } }],
  "toolResults": [{ "name": "get_stock_quote", "ok": true, "data": { } }],
  "trace": ["route→data", "plan→get_stock_quote", "execute→1 tools", "synthesize→done"]
}
```

编排实现为 LangGraph 风格线性图：`route → plan → execute → synthesize`（见 `apps/orchestrator/src/graph/`）。

**工具约束**：最多 5 轮；单工具超时 30s；异常回填给调用方（后续交模型决定是否重试）。

| 工具名 | 下游 | 参数 |
|---|---|---|
| `get_stock_quote` | Market-Data `/quotes/{symbol}` | `symbol` |
| `search_reports` | Research `POST /rag/search` | `query` |
| `get_cn_equity_quote` | Research `/cn-equity/quotes` | `codes` |
| `compute_factor_ic` | Research `POST /factors/ic` | `factor=momentum`, `windowYears`, `universe`, 可选 `lookback`/`horizon` |
| `run_backtest` | Research `POST /backtests/run` | `strategy`, `fast`, `slow`, `universe` |

## Research（内部 `:8002`）

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/health` | 存活 |
| GET | `/ready` | 就绪 + Qdrant 探测 |
| POST | `/rag/search` | 研报检索（Qdrant 感知 stub；hits 仍可为 demo） |
| POST | `/rag/collections/ensure` | 幂等创建研报向量集合 |
| POST | `/factors/ic` | 单标的动量**时序** Spearman IC/ICIR；日线优先 `market.bar_daily`；`demo=false` 且带 `source`/`assumptions`（非截面 alphalens） |
| POST | `/backtests/run` | 双均线回测；A 股日线优先冷库（见下行） |
| GET | `/cn-equity/*` | 中国 A 股产品面；`codes?category=`、`index-strip`、报价/K 线可带交易所；历史优先 `market`、盘中 qdb；见 [模块边界](../market/2026-10-26-行情模块边界.md)、[cn-equity](../market/2026-10-26-cn-equity.md) |
| GET | `/cn-equity/fundamentals/{code}` | 个股冷域摘要：资金流 / 财务 / 股本 / 申万 / 解禁（只读 `market`；`flow_limit`、`finance_reports`） |
| GET | `/cn-equity/plates` | 板块目录（`vendor=east\|ths`，可选 `q`） |
| GET | `/cn-equity/plates/{vendor}/{plate_code}/members` | 板块成分 |
| GET | `/cn-equity/plate-flow` | 板块资金流日终快照 |
| GET | `/cn-equity/sentiment/summary` | 两融 / 北向 / 热榜摘要（北向可空） |
| GET | `/cn-equity/lhb` | 龙虎榜（必填 `date=YYYY-MM-DD`） |
| GET | `/cn-equity/lhb/{list_id}/detail` | 龙虎榜席位明细 |
| GET | `/cn-equity/lhb-days` | 有龙虎榜数据的交易日列表 |
| POST | `/backtests/run` | 双均线回测；A 股日线优先 `market.bar_daily`，`source` 标明 |

**RAG**

```json
{ "query": "宁德时代核心观点" }
```

**因子 IC（动量时序）**

```json
{
  "factor": "momentum",
  "windowYears": 3,
  "universe": "600519",
  "lookback": 20,
  "horizon": 5
}
```

响应含 `ic` / `icir` / `n_obs` / `bars`；`mode=cold_ts_ic`（冷库有数时）；`demo=false`；`source` 标明棒来源；`assumptions` 说明因子=过去收益、标签=前瞻收益。仅支持 `momentum`；冷库空或样本不足 → **422**（不回落伪随机）。

**回测（`dual_ma`）**

请求：

```json
{
  "strategy": "dual_ma",
  "fast": 20,
  "slow": 60,
  "universe": "600519.SH",
  "period": "1d",
  "count": 120,
  "adjust": "none"
}
```

响应含 `metrics`（`cum_return` / `max_drawdown` / `trades` / `bars`）与 `equity_curve[]`。`mode=market_bars`；A 股日线优先 `market.bar_daily`（`source`/`data_source`）。前端：`http://localhost:3001/backtest`（BFF `POST /api/backtests/run`）。

## Market-Data（`:3002`，亦可经网关 `/api/market`）

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/health` | 存活 |
| GET | `/quotes/{symbol}` | 实时快照；Redis TTL≈3s；`binance` Provider 读 qdb |
| GET | `/bars/{symbol}?period=1d&count=60&adjust=none` | 历史 K 线 |
| GET | `/search?q=` | 标的搜索 |
| GET | `/exchanges` | 已注册交易所目录 |
| GET | `/exchanges/binance` … | 币安现货；**只读 qdb**（`/binance` 为别名）。`ping`→`{}`；`time`→本地 millis；`exchangeInfo`/`ticker`/`depth`/`trades`/`klines`→qdb docs 或折叠。**禁止**回源 |
| GET | `/binance/v3/{*path}` | **403 forbidden**（qdb-only；拒绝上游透传） |
| GET | `/binance/klines?symbol=&interval=&limit=&endTime=` | K 线**窗口读**（默认 limit≈200；`endTime` 毫秒向前翻历史）；勿一次拉全量 |
| GET | `/exchanges/binance/rwa/*` | Ondo 代币化美股；stocks / **board**（`?tickers=AAPL,NVDA`）/ status / dynamic / quote / **klines**（优先 `rwa:kline:*`）**只读 qdb**；禁止 bapi |
| GET | `/binance/rwa/klines?…&limit=&endTime=` | RWA K 线同样窗口读 |
| WS | `/exchanges/binance/ws` | **拒绝上游**（连上即返回 error JSON）；请用 `/qdb/ws` |
| WS | `/qdb/ws` | **唯一订阅读**：代理到 qdb `GET /v1/ws`（SELECT … SUBSCRIBE）；直连 `:3002`；`/exchanges/qdb/ws` 同 |

Provider 由 `MARKET_PROVIDER` 选择：`mock`（默认）| `binance`（统一 `/quotes` `/bars` `/search` 也读 qdb）。`alphafeed` 仍可选但**一律拒绝外呼**（请改用 `binance`/`mock`）。

## MCP Server（stdio）

目录：`apps/mcp-server`。工具：`get_stock_quote`、`get_daily_bars`、`search_reports`、`query_factor_ic`、`run_backtest`。

```bash
cd apps/mcp-server && npm run build && \
  MARKET_DATA_URL=http://127.0.0.1:3002 RESEARCH_URL=http://127.0.0.1:8002 npm start
```

客户端以 stdio 接入；不进 Compose 默认拓扑（本地/IDE 侧车）。

## 冒烟示例

```bash
curl -s http://localhost:3000/health
curl -s http://localhost:3000/api/market/quotes/600519.SH
curl -s -X POST http://localhost:3000/api/chat \
  -H 'content-type: application/json' \
  -d '{"message":"计算动量因子过去3年IC"}'
curl -s -X POST http://localhost:3000/api/chat \
  -H 'content-type: application/json' \
  -d '{"message":"跑一个双均线策略，20/60日"}'
```
