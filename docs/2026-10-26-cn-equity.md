## 命名

| 层 | 名称 |
|---|---|
| 研究 API | `/cn-equity/*`（旧 `/ashare/*` 兼容） |
| BFF | `/api/cn-equity/*` |
| 前端 | `/markets/cn`（旧 `/markets/ashare` redirect） |
| 采集源登记 | Postgres `market.data_source` 中的 `sina` 等 |

## 读路径

- **盘中**：只读 qdb（snapshots / 未闭合棒 / docs）。
- **历史**：优先 Postgres `market.bar_*`（见 [域模型](./2026-10-26-market-postgres-schema.md)）；缺则回落 qdb。
- **禁止**读路径回源公开上游。

## 主要接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/cn-equity/codes` | 代码表 |
| GET | `/cn-equity/quotes` | 报价 |
| GET | `/cn-equity/klines/{code}` | K 线；`view=history\|realtime\|merged` |
| GET | `/cn-equity/five/{code}` | 五档 |
| GET | `/cn-equity/intraday/{code}` | 分时（5m 合成） |
