# 行情模块边界（硬性）

> 创建日：2026-10-26。本文是行情数据面的 **模块职责与禁令 SSOT**。  
> 表结构见 [market-postgres-schema](./2026-10-26-market-postgres-schema.md)；A 股产品面见 [cn-equity](./2026-10-26-cn-equity.md)；qdb 协议见同级仓手册 + [qdb-行情库](./2026-10-20-qdb-行情库.md)。

## 1. 一句话分层

| 模块 | 一句话 | 可写 | 可读 |
|---|---|---|---|
| **上游（Upstream）** | 公开行情供应商（新浪、币安、RWA bapi…） | — | **仅 collector** |
| **data_source** | 供应商在库内的登记码（`sina` / `binance`…） | collector | 运维/对账；**不是** API 资源名 |
| **collector** | 唯一回源进程 | → qdb **与** → Postgres `market` | 上游 |
| **qdb（热）** | 盘中快照、未闭合棒、订阅、短窗引擎 K | collector | research / market-data / 经代理的前端订阅读 |
| **Postgres `market`（冷）** | 已闭合历史棒、复权因子、交易日历、停牌 | collector（及明确授权的迁移 job） | research（历史）；回测/翻历史主读 |
| **cn-equity** | 中国 A 股**产品**读面（API/UI 名） | 不写存储 | 读 qdb + `market`；对外路径 `/cn-equity` |
| **market-data** | 币安/RWA 等非 A 股读适配 + `/qdb/ws` 代理 | 不写行情库 | **只读 qdb**（本阶段不读 `market`） |
| **gateway / BFF / frontend** | 传输与展示 | 不写行情库 | 只打本仓 API；零上游 |

```text
上游 ──(唯一)──► collector ──┬──► qdb（热）
                             └──► Postgres market.*（冷）
                                      ▲
research /cn-equity ── history ───────┘
                 └── realtime / quotes / depth / ws ──► qdb
market-data ─────────────────────────────────────────► qdb
frontend / BFF / gateway ──► research | market-data（禁止直连上游或直打 QDB_URL /v1）
```

## 2. 禁止混淆的三组名字

| 易混 | 正确归属 | 禁止 |
|---|---|---|
| `sina` / `adata` / `binance` | **仅** `market.data_source.code` 或 collector 实现细节 | 作 OpenAPI tag、路由段、产品模块名 |
| `ashare` | **仅**兼容别名（旧 `/ashare`、旧 docs key `ashare:codes`） | 新代码、新文档标题、新页面路径 |
| `cn-equity` / `/markets/cn` | **产品/市场段**名（中国 A 股） | 当作采集供应商名 |
| `qdb` | 热存储与引擎 | 当作「全量历史库」或业务资源名 |
| `market` schema | 冷历史域模型 | 与 qdb docs/quotes 混写同一条写入路径而不标明 |

## 3. 各模块允许 / 禁止

### 3.1 上游

- **允许**：被 collector 拉取。
- **禁止**：出现在 research、market-data、frontend、orchestrator、gateway 业务转发的任何 HTTP/WS 客户端中。

### 3.2 collector

- **允许**：访问上游；经 `packages/qdb-*` 写 quotes/trades/docs；经 `pg_market`（或等价）写 `market.*`；维护水位。
- **禁止**：被其它服务「代写」；读路径服务不得 import collector 回源逻辑。
- **落点**：`services/collector/`（含 `pg_market.py`）。

### 3.3 qdb（热）

- **存**：snapshots、未闭合 / 短窗 K、docs（如代码表、五档）、订阅流。
- **不存（权威）**：长期已闭合历史的主副本、复权因子序列、交易日历权威表、停牌区间权威表——这些以 `market` 为准。
- **访问**：一律 `packages/qdb-{py,ts,rs}`；业务禁止裸打 `QDB_URL/v1/*`。
- **浏览器**：订阅读经 market-data `/qdb/ws`，订阅逻辑用 TS 客户端。

### 3.4 Postgres `market`（冷）

- **存**：`security` / `bar_daily` / `bar_minute` / `adjust_factor` / `trading_calendar` / `suspend` / `data_source` / `ingest_watermark`。
- **不存**：盘中未闭合棒、WebSocket 推送状态、研报向量、会话审计（后两者在别的 schema/库）。
- **价格**：交易所原始价；**不存**三份复权 OHLC 行。
- **写者**：默认仅 collector；手工迁移须标明 `data_source=manual`。
- **落点**：`infra/postgres/migrations/*market*`；设计文 [market-postgres-schema](./2026-10-26-market-postgres-schema.md)。

### 3.5 cn-equity（产品读面）

- **是**：中国 A 股对外契约与研究层模块（`apps/research/app/cn_equity`、路由 `/cn-equity`、前端 `/markets/cn`）。
- **读规则**：
  - `view=history` / 翻历史：**优先** `market.bar_*`；不足可回落 qdb（须在响应 `source` 标明）。
  - `view=realtime` / quotes / five / 订阅相关：**只** qdb。
  - `view=merged`：history（PG 优先）+ realtime（qdb）在研究层拼接。
- **禁止**：回源上游；把 `adata`/`ashare` 写进新 OpenAPI tag；在 BFF 拼上游 URL。
- **兼容**：`/ashare`、`/api/ashare`、`/markets/ashare` 仅为别名/redirect，文档标注废弃。

### 3.6 market-data

- **职责**：币安现货、RWA/Ondo 等；qdb 读适配；`/qdb/ws` 代理。
- **禁止**：代理币安/RWA 上游 REST/WS；本阶段读 `market` schema（A 股历史不经此服务）。
- **与 cn-equity**：市场段不同；勿把 BINANCE/ONDO 混进 A 股列表。

### 3.7 gateway / BFF / frontend

- **允许**：反代 `/api/research/cn-equity/*`、`/api/market/*`；展示派生指标（MA 等）仅基于已取回序列。
- **禁止**：直连上游；浏览器直打 `QDB_URL`；把采集源名当导航产品名。

## 4. 读写顺序（门禁）

与 DoD 数据面一致：

1. collector 写入就绪（qdb 有报价/docs；历史则 `market.bar_*` 有行或水位推进）  
2. research / market-data 读通  
3. frontend 展示  

逆序不得报绿。展示集 ⊆ 采集就绪集（或明确「仅目录、暂无报价」）。

## 5. 响应里的 `source` 语义

| 值 | 含义 |
|---|---|
| `qdb` | 本响应主体来自 qdb |
| `postgres` / `postgres:market` | 本响应主体来自 `market` schema |
| `qdb:ashare:codes` 等 | docs key 遗留名；**不是**产品模块名 |
| `sina` | 仅允许出现在采集侧元数据 / `data_source`，不应作为读 API 的主 `source` 宣称「业务来自新浪」 |

## 7. 验收清单（文档与行为）

- [ ] 新路由/包名不含 `adata`；不含非兼容用途的 `ashare`
- [ ] 读路径无上游域名
- [ ] 历史 K 主读 PG；盘中主读 qdb；`merged` 拼接点只在 research
- [ ] collector 同时具备 qdb 写与 `market` 写（或缺省说明为何跳过 PG）
- [ ] market-data 无 A 股历史职责声明
